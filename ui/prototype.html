◆ Studio Lab / progressive disclosure, same local worker

More control when you want it.

Capture stacks, procedural surfaces, editable projects, set repair, DCC delivery and an encrypted vault. Auto Forge stays the front door.

Bracketed capture stack

Pick two to twelve PNG frames of the same subject. Frames must share one size. Median rejects transient details; mean reduces noise. The merged frame goes through the normal PBR pipeline.

What it is honest about

This aligns exposure and combines pixels; it does not align geometry or register handheld frames. Use a tripod or a fixed camera. JPEG frames must be converted to PNG first.

2–12 frames PNG in, PNG out Local only

Procedural surface

Generate a tileable albedo, height, normal, roughness and AO source. Preview is generated on this machine; Forge sends the albedo through the normal seam/QC pipeline.

Albedo preview

Choose a pattern and press Preview.

New material project

A project keeps the source and an ordered, non-destructive layer stack. Rendering writes a fresh library material; the project itself is never overwritten by the pipeline.

Saved projects

Render uses the project's stored pipeline options. Deleting a project never deletes a library material it already produced.

No projects loaded.

PBR Set Doctor

Scans a library material or a flat texture folder for role, size, bit-depth and naming problems. Repairs are written into a new folder; originals are never silently replaced.

Report

Select a material and press Scan.

DCC & interchange delivery

Copies the existing maps (pixels are not re-encoded) and writes MaterialX 1.38, a glTF 2.0 fragment, a USD Preview Surface, and a Blender node script. These are interchange files, not renderer certification.

Generated files

Choose a material and generate the delivery folder.

Encrypted local backup

Creates an AES-256-GCM vault with scrypt key derivation. The passphrase never leaves this request and is never stored. Keep it somewhere other than the backup itself.

Security audit

Checks pairing auth, TLS, the vault backend and response headers. It does not claim to protect against local code execution or a compromised operating system.

Press Run audit for the current posture.
