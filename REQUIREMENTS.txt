# PBRForge requirements
# ===========================================================================
#
#  PBRForge 2.0 is a local studio, not a web service.
#
#  WINDOWS INSTALLER
#      No Python, pip or compiler is needed. The single-file build bundles
#      Python 3.12 and cryptography. Download PBRForge-Setup-2.0.0.exe.
#
#  SOURCE CHECKOUT
#      Python 3.11+ (3.12 is the build target).
#      One runtime dependency: cryptography >= 42.
#
#          py -3.12 -m pip install cryptography
#          py -3.12 -m pbrforge selftest -v
#          py -3.12 -m pbrforge serve
#
#  WHY ONLY ONE THIRD-PARTY PACKAGE?
#      The PNG codec, colour-space gate, tileable synthesis, server, CLI,
#      jobs, projects, Set Doctor, capture, delivery and watch folders are
#      standard-library Python. cryptography is used only for:
#
#          * AES-256-GCM encrypted .pbrvault backups (scrypt KDF);
#          * Ed25519 release-signature verification;
#          * local TLS certificates for LAN clients.
#
#      The imaging pipeline does not need numpy, Pillow, OpenCV, libvips or a
#      GPU. Installing those will not unlock hidden features, because v2 does
#      not contain any that use them.
#
# ---------------------------------------------------------------------------
#  RUNTIME
# ---------------------------------------------------------------------------
cryptography>=42

# The version is pinned by the release build, not by this floor. The installer
# carries a tested wheel; a source checkout only needs a current cryptography.
#
# Lazy imports are intentional: ordinary Auto Forge jobs do not touch this
# package. Vault, release verification, security audit and `tls init` do.


# ---------------------------------------------------------------------------
#  DEVELOPMENT AND PACKAGING -- never needed by an installed user
# ---------------------------------------------------------------------------
# PyInstaller builds dist/pbrforge.exe. Inno Setup is a Windows application,
# not a pip package.
#
# pyinstaller>=6.6
# pytest>=8.2
# ruff>=0.5
#
# winget install JRSoftware.InnoSetup
#
# Build:
#   powershell -ExecutionPolicy Bypass -File deploy\build-installer.ps1
#
# Test:
#   python -m pbrforge selftest -v
#   python -m compileall -q pbrforge


# ---------------------------------------------------------------------------
#  EXPLICITLY DEFERRED -- do not install these expecting features
# ---------------------------------------------------------------------------
# OpenEXR / OpenImageIO   Not implemented. v2 reads and writes PNG. EXR is on
#                         the roadmap but is not claimed as working.
# numpy / OpenCV / torch  Not used by the v2 pipeline.
# Local AI                Not implemented. There is no model download, no
#                         inference runtime and no prompt-to-texture feature.
#
# A deferred feature is not a hidden switch. The README and `pbrforge doctor`
# say so plainly.
